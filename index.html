The problem

L'organisation d'évènements — conférences, ateliers, meetups — disperse la publication, la validation et les inscriptions entre plusieurs outils. Il fallait une plateforme unique avec un circuit de modération clair entre organisateurs et administrateur.

  • Full containerisation with Docker Compose

The problem

Developers rarely get a quick read on the real state of their projects: vulnerable dependencies, secrets left in the code, poor Docker practices — risks that go unnoticed without a regular audit, which is slow to run by hand.

  • Five analysers chained in isolation: npm audit, gitleaks, ESLint/SonarJS, Hadolint, GitHub Actions workflow audit

  • Findings summarised in plain language via the Mistral API

JobMatch AI

Assistant IA qui génère des candidatures personnalisées à partir d'un CV et d'une offre d'emploi.

An AI assistant that writes tailored applications from a CV and a job posting.

ReactNode.jsExpressPostgreSQLPrismaMistral AIJWT
Voir en ligne ↗ Live demo ↗ GitHub ↗

Le problème

The problem

Adapter une candidature à chaque offre est répétitif : relire l'annonce, identifier les compétences clés, rédiger une lettre pertinente — sans jamais travestir le profil réel du candidat.

Tailoring an application to every posting is repetitive: re-read the ad, spot the key skills, write a relevant letter — without ever misrepresenting the candidate's real profile.

Approche

Approach

  • Authentification sécurisée (JWT + bcrypt) et upload de CV en PDF
  • Extraction du texte du CV et parsing structuré côté serveur
  • Analyse d'offre par IA (Mistral) : compétences techniques, humaines et niveau d'expérience extraits en JSON
  • Lettre de motivation personnalisée + score de correspondance, avec retry automatique sur les erreurs d'API
  • Déploiement complet : PostgreSQL (Neon), backend (Render), frontend (Vercel), monitoring anti-veille (UptimeRobot)
  • Secure auth (JWT + bcrypt) and PDF CV upload
  • CV text extraction and structured parsing server-side
  • AI job-ad analysis (Mistral): technical skills, soft skills and seniority extracted as JSON
  • Tailored cover letter + match score, with automatic retry on API errors
  • Full deployment: PostgreSQL (Neon), backend (Render), frontend (Vercel), uptime monitoring (UptimeRobot)

Résultats

Results

  • Pipeline complet CV → offre → lettre, de bout en bout
  • Score de correspondance honnête : le prompt interdit d'inventer des compétences absentes du CV
  • Démo en ligne stable et réactive (cold start Render résolu)
  • Complete CV → posting → letter pipeline, end to end
  • Honest match score: the prompt forbids inventing skills absent from the CV
  • Stable, responsive live demo (Render cold start solved)
